# Zenless Zone Zero Agent Toolkit — feature reference

Zenless Zone Zero Agent Toolkit focuses on three connected areas: agent profiles, equipment notes, activity planning. Its organization keeps frequently used options close to the context they belong to.

| Section | Description |
|---|---|
| Agent profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Equipment notes | Equipment categories and the associated selection or configuration options. |
| Activity planning | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
